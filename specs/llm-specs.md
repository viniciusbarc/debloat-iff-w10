# Siga rigorosamente as regras existentes neste arquivo

## Contexto geral do projeto

- O projeto é criar um script para executar nas máquinas com Windows 10 dos laboratórios do IFF, a fim de desinstalar programas e configurações desnecessárias e melhorar o desempenho das máquinas.
- Unifique todas as funcionalidades em um único script.
- Coloque comentários simples mas precisos do por quê de cada ação. 
- Sempre utilize o idioma português do Brasil para os comentários.
- O script deverá executar em PowerShell no modo administrador, de forma silenciosa, ou seja, sem perguntar nada ao usuário.
- O projeto Win-Debloat-Tools-main servirá de guia para a criação do script.
